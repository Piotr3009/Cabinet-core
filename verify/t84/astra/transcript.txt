1. Szybka karta: maksymalnie sześć pozycji

Przy tak krótkiej liście zrezygnowałbym z zakładek Size / Build. Wszystkie podstawowe ustawienia mieszczą się jednocześnie. Zakładki dokładałyby kliknięcie.

Typ	Proponowane pozycje — angielskie etykiety
Base cabinet	Width · Height · Depth · Front type · Finish · Plinth
Wall cabinet	Width · Height · Depth · Mount height · Front opening · Finish
Wardrobe	Width · Height · Depth · Front type · Finish · Bays
Vanity	Width · Height · Depth · Drawers · Sinks · Mounting
Mirror cabinet	Width · Height · Depth · Mount height · Bays · Recess

To propozycja do omówienia, nie zatwierdzenie schowania wszystkich pozostałych ustawień.

Istotne wyjątki:

HAWA: Calculated size jest informacją, nie trzema edytowalnymi wymiarami. Hand pokazujemy tylko tam, gdzie dotyczy.
Wardrobe: Bays to podsumowanie istniejących przegród. Nie dodajemy nowego, uproszczonego settera liczby sekcji.
Mirror: zmiana Bays musi zachować ostrzeżenie o przywróceniu domyślnych szerokości drzwi.
Free panel: pokazujemy wymiary fizycznej płyty, nie jej obróconej bryły.
Szafki narożne L: istniejące nazwy Arm A / Arm B zastępują Width / Depth.
Finish: otwiera istniejący wybór wykończenia. Nie zastępuje przypisania płyty magazynowej.
Pod kartą rozdzielam dwie różne czynności: Open cabinet otwiera edytor mebla, a Full settings pokazuje pełny panel parametrów.

2. Pełny panel: grupy, które mogą pozostawać otwarte jednocześnie

Dla stolarza zmieniającego dziesięć rzeczy pod rząd wybrałbym jeden przewijany panel z niezależnie rozwijanymi grupami, pamiętający ich stan i pozycję przewijania.

Docelowo proponuję grupy:

Layout — wymiary, położenie, bays, przegrody;
Construction — płyty, plecy, połączenia, Cabineo, notche;
Fronts & hardware — fronty, zawiasy, prowadnice;
Interior — półki, szuflady, wyposażenie;
Finishes & lighting — wykończenia i LED.
Nie robiłbym obowiązkowego przełączania między zakładkami. Wyszukiwanie może później prowadzić do konkretnego pola, ale nie powinno być podstawowym sposobem obsługi.

Etap 1 zachowuje obecny panel. Samo opakowanie RightPanel.jsx nie stworzy prawdziwych grup ani wyszukiwarki. Ich uporządkowanie byłoby osobnym etapem, bez ukrywania przypadkowych wierszy przez CSS. Błędy pozostają widoczne również przy zwiniętej sekcji.
