# T75 PROBE, PART C: kitchen kits F12 to F15

What was probed: everything on main that F12 (the appliance tower), F13 (the base
unit with drawers behind its doors), F14 (the hob unit) and F15 (the plain pelmet)
would build on. How: the code was read at `HEAD` (f60d18f, "claude tura 75"), and
every file:line below is pinned to `HEAD`, because the integrator is editing
`cabinet.js`, `profile.js`, `runs.js`, `partRegistry.js` and `projectStore.js` in
the working tree at the same time. Behaviour was MEASURED with node scratch
scripts run against a `git archive HEAD` export in the scratchpad (and, for
comparison, against the working tree: FRIDGE, BUDR, BUDR2, DW_PANEL, OVEN_BASE and
PANTRY gave byte-identical output in both). F13 was measured with an IN-MEMORY
probe type (`UNIT_TYPES.BUD_INT_PROBE = { ...BUD, drawerStyle: 'wardrobe',
internalDrawers: 'all', supports.drawers: true }`, set inside the scratch process
only, never written to a file). The six goldens (`scripts/t64-classify.mjs dump()`)
were checked against `verify/t70/goldens-base.json`: all six IDENTICAL at the start
of this probe. No repository file other than this one was written.
