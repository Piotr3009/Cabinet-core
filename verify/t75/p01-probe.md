# T75 PROBE, PART A (first half): corners F1 to F3

What was probed: everything on MAIN that F1 (the corner rulebook), F2 (the corner post, the corner stop, rule 7, the hinge law at a corner) and F3 (the three blind kits) would extend, copy or collide with. How: `git archive HEAD` (commit f60d18f) was unpacked into a scratch folder so that the integrator's work in progress in the working tree could not leak into the answers; every line number below is HEAD's. Behaviour was MEASURED with node scripts that drive the real store (`useProjectStore`: `newProject`, `setRoom(rectCorners(4000, 3000))`, `addUnit`, `moveUnit`, `moveUnitToWall`, `setDoors`, `frontClearances`, `unitResult`, `validateUnit`), the retail adapter (`addFirstWardrobe` with `setWardrobeEndPanelAuto(true)`), `computeCabinet` and the T64 golden hash (`scripts/t64-classify.mjs` `dump()` shape against `verify/t70/goldens-base.json`). The room in every scene is 4000 x 3000: wall 0 runs (0,0) to (4000,0), wall 1 runs (4000,0) to (4000,3000), so the wall 0 END and the wall 1 START are the same internal corner. Unit A is a cabinet driven to the right end of wall 0 (it occupies the corner square); unit B is a cabinet put on wall 1 at x 1500 and then dragged towards x 0 (into the corner).
