# T75 PROBE, PART D: wardrobe kits F16 to F19

What was probed: every place on main that F16 (chest of drawers between wardrobes), F17 (floating desk), F18 (low
units of a wardrobe job) and F19 (hooks, valet rod) would copy from, plug into or collide with. How: the source was
read at HEAD `f60d18f` (every file:line below is HEAD's; the working tree's `src/engine/cabinet.js` already carries
the integrator's PART A edits, so its lines from about 8400 on are shifted by +49 there), and behaviour was MEASURED
with node scratch scripts that import the real engine and the real store and, IN MEMORY ONLY, register the
would-be kits (`UNIT_TYPES.WARDROBE_CHEST3 = { ...BUDR, family: 'wardrobe', legSource: 'wardrobe', ... }`,
`WARDROBE_LOW = { ...LOW_CABINET, family: 'wardrobe' }`, `WARDROBE_DESK = { ...WUD, family: 'wardrobe', drawerStyle:
'budr', ... }`). No repository file was edited. The six goldens (`scripts/t64-classify.mjs dump()` against
`verify/t70/goldens-base.json`) were identical when measured.
